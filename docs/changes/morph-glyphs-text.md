# MorphGlyphs keeps unchanged text

## Why

A ticking clock should be one `TextBlock` that calls `Recipes.MorphGlyphs` each second. Today it cannot be, and Tempo's countdown works around four findings (BACKLOG, BRIDGE-RECIPES, Tempo findings):

- **Font features are dropped.** The text splits and glyph outlines ignore `FontFeatures` (`TextSplitter.Copy` copies family, size, style, weight, stretch and letter spacing; `GlyphOutlines.Path` shapes with none), so a block with tabular figures (`+tnum`) would morph on proportional slots and jump when it unsplits. Inter's figures are proportional, so Tempo puts each digit in its own fixed-width, centered block.
- **Unchanged characters re-render.** `MorphGlyphs` turns every pair into an outline piece, equal ones included, so a whole-block clock redraws its unchanged digits as unhinted outlines every second. Its colon also hops. Every piece is shaped alone, and Inter's `calt` swaps a colon between figures for the raised `colon.case` (checked in the font's GSUB), which a lone `:` never gets. So Tempo has one block per character and morphs only the blocks that changed (`FocusView.ShowRemaining`).
- **Every call costs the same.** Each call splits the block twice, reads an outline for every old and new character, and adds an overlay host `Canvas` even when no character needs a ghost.
- **Reduced motion has no instant form.** Under reduced motion `MorphGlyphs` crossfades the whole block. That suits a label that changes now and then, but a ticking counter then flickers every second. Tempo writes `Text` directly under `Presto.Defaults.ReducedMotion` for the countdown, the start/pause label and the settings `Stepper`.

## What

`MorphGlyphs` stops splitting the block. The block stays one laid-out `TextBlock` that shows the new text from the first frame, so it keeps its own shaping (kerning, `calt`, `FontFeatures`), its hinting and its automation text. Only the characters that move are drawn as pieces:

```csharp
// Tempo's countdown, after: one block, FontFeatures="+tnum".
Recipes.MorphGlyphs(Remaining, text, reduced: ReducedMorph.Instant);
```

- **Classifying.** Pairing is unchanged (BRIDGE-RECIPES-085): position j with old position j, or from the end for numbers. "From the end" now also covers numerals such as `25:00` and `120:00`. For each pair, both slots and outlines are read from the block's own `TextLayout`, before and after the text is set, so they are exactly what the block draws. A pair whose two graphemes are equal and whose slot has not moved in the window **stays**. Every other pair **moves**.
- **Drawing.** A character that stays is the block's own text, untouched. A character that moves is hidden in place in the block, and a piece plays it in a `Canvas` in the block's adorner layer, which follows the block's layout and render transforms (Tempo's digits sit in a `Viewbox`). Paired outlines morph from the old slot into the new one as today. Equal graphemes whose slot moved (a centered `9:59` → `10:00`) slide their outline without reshaping. Unpaired characters grow from or collapse into their slot center. A pair without an outline crossfades. Leaving characters are outline `Path`s filled with `Foreground`, not bitmap snapshots, and a character without an outline draws as a text piece.
- **Nothing to do, nothing done.** When no pair moves (the same text, or only stays), `MorphGlyphs` sets `Text` and returns a completed `Timeline`. It adds no host, holds no width and hides nothing. Otherwise there is exactly one host, and every piece in it moves.
- **End.** On completion the hidden characters show, the host leaves the adorner layer and the width hold is released. The block ends as plain `Text`, as today.
- **Reduced.** A new optional `reduced` parameter, `ReducedMorph.Crossfade` (default, today's behavior) or `ReducedMorph.Instant`. Instant sets `Text` at once and returns a completed `Timeline`, so a ticking counter neither morphs nor flickers.
- **Font features in splits.** `TextSplitter` and `GlyphOutlines` (and so `WriteIn`, `MorphText`, `Shatter`, the reveals, `GlyphOutline` and `TextOutline`) shape with the block's `FontFeatures`. That makes tabular slots tabular in every split.

What does not change: pairing positions, durations and eases (`Tokens.Long`, `Ease`, `EmphasizedEase`), the shared running table (-089), completion on detach (-096), `SetCurrentValue` writes (-097), the width hold (-081/-088), the crossfade default, and `MorphText`, `WriteIn` and `Shatter`, which keep splitting.

## Decisions

- **`MorphGlyphs` hides characters in the block instead of splitting it.** Changed characters are hidden by laying the block's text out as `Inlines`, where each hidden grapheme is a `Run` with a transparent `Foreground`. Pieces play in the block's adorner layer. Reason: a stay must look exactly like the plain text, and only the block's own layout achieves that. Any split shapes each piece alone, which drops Inter's raised colon and kerning, and turns the stay into an unhinted outline. A foreground-only `Run` boundary is assumed to keep shaping context, because Avalonia shapes runs that differ only in brush together. Task 2 pins that assumption first (see the `OpacityMask` fallback below). Rejected: keeping the split and making stays text pieces, which still drops the colon's `calt` and kerning; shaping whole lines inside the splitter, a rewrite of every split user's slot model for one recipe.
- **Pieces live in the adorner layer, not the overlay layer.** Reason: the adorner layer applies the adorned element's transform, so a morph in a scaled `Viewbox` or under a `RenderTransform` lines up with the text it replaces. The overlay ghosts `MorphGlyphs` draws today are placed in window coordinates at snapshot size, which is wrong under a scale. Rejected: the overlay layer (wrong under scale); a decorator wrapped around the block (it would change the visual tree the app built). A block with no adorner layer completes at once, as a detached block does (-098).
- **Slots and outlines come from the block's `TextLayout`.** Slots come from `HitTestTextRange` per grapheme, and outlines from the glyphs the layout shaped for that grapheme. Reason: they are then what the block draws, in context and with its features, so the end swap from piece to text cannot jump. Rejected: shaping each grapheme alone, today's `OutlineOf`, which is where the colon hop comes from.
- **Equal pairs stay by default, with no opt-out.** Reason: morphing a glyph onto itself in the same place shows nothing except the hinting swap and the context loss, so no caller wants it. Rejected: an opt-in `keepEqual` flag, which would leave the default broken for clocks.
- **A stay needs the same grapheme and the same window position, within 0.1 DIP on each axis.** Otherwise the pair slides. Reason: tabular and end-aligned texts lay equal characters out at identical positions, while a centered or proportional block shifts them. A stay shows the new position from the first frame, so a moved stay would jump. 0.1 DIP absorbs the window-origin correction's float noise, and any visible shift slides instead. Rejected: comparing graphemes only (a centered block's equal characters would jump); comparing slots in block coordinates (a centered block moves in its parent as its width changes).
- **Numerals pair from the end too.** Both texts pair from the end when both parse as numbers in the current culture (as today), or when both consist only of decimal digits, white space and punctuation with at least one digit. Reason: a clock string (`120:00` → `99:59`, `9:59` → `10:00`) is a number in meaning but not to `double.TryParse`. From the start it would pair `1` with `9` and `:` with `5`, and morph every character. Rejected: `TimeSpan` parsing (`120:00` fails as hours); a caller-supplied alignment parameter, since the rule covers clocks, counters and scores without one.
- **Leaving characters are outlines, not snapshots.** Reason: a vector piece filled with `Foreground` costs no bitmap and stays sharp at any scale. It also removes the likely cause of the body-size specks (see Spec changes). Characters without an outline (emoji, color glyphs) draw as text pieces in the block's font. Rejected: keeping `Presence.Snapshot` ghosts.
- **The reduced form is a per-call choice, `ReducedMorph`, defaulting to `Crossfade`.** Reason: on one page a counter wants `Instant` and a button label wants the crossfade, so it belongs to the call, not to `Tokens` or `Defaults`. An enum reads at the call site (`reduced: ReducedMorph.Instant`) and leaves room for another form. Rejected: a bool `instant` (reads as the full form being instant); detecting ticking from call frequency (magic, and the first tick still flickers); making `Instant` the default (a label swap with no transition loses the change cue the crossfade gives).
- **`MorphText` keeps its crossfade.** It is a title effect, not a ticking one, and nothing has asked for an instant form. Adding the same parameter later is additive.
- **Font features reach the splitter and outlines.** The split's measuring copy and every outline shaping take the block's `FontFeatures`. `TextOutline` gains an optional `fontFeatures`. Reason: with features ignored, a `+tnum` block splits on proportional slots and jumps at revert, in every split recipe, not only `MorphGlyphs`. Per-piece shaping still loses contextual alternates, which is logged rather than fixed (BRIDGE-TEXT Open items).
- **If a foreground-only `Run` breaks shaping, an `OpacityMask` hides the moving slots.** The mask's transparent rectangles over the moving slots are set at `Animation` priority, so an app's own mask returns afterward. Reason: it leaves the block's shaping untouched; the cost, clipping ink a neighbor overhangs into a moving slot, is negligible for tabular figures. Task 2 decides which of the two ships.
- **The Gallery Morph clock is one `HH:mm:ss` block with tabular figures, and its colon pulse goes.** Reason: it is the case this change exists for, its snippet shrinks to one call, and otherwise the countdown would be the only single-block demo. Rejected: three blocks with pulsing colon blocks.

## Spec changes

**BRIDGE-RECIPES** (`docs/specs/avalonia-bridge/recipes.md`): add `ReducedMorph` to `types` and `MonacoLabs.Presto.Avalonia/ReducedMorph.cs` to `sources`.

- **-085** changed: `MorphGlyphs` shall pair the new text's character at index `j` (counting as a character split does) with the old one at `j`, or at `j + old count − new count` when both texts parse as numbers in the current culture, or both consist only of decimal digits, white space and punctuation with at least one digit, so the last characters pair.
- **-086** changed: `MorphGlyphs` shall not split the block. It shall set `Text` to `text`, keep every character that stays drawn by the block, hide each character that moves in place without changing the block's layout, and play the moving characters as pieces in a canvas in the block's adorner layer. A pair where both characters have an outline shall morph from the old character's outline at its old slot into the new one's at its slot, over `Tokens.Long` with `Tokens.Ease`. Slots and outlines are those of the block's own text layout, before and after the change.
- Added: A pair whose graphemes are ordinally equal and whose slot in the window has moved by no more than 0.1 DIP on either axis shall stay: no piece, no hiding, no animation.
- Added: A pair whose graphemes are equal but whose slot moved further shall slide its outline from the old slot to the new one without reshaping, as -086.
- **-087** changed: A new character without a partner shall grow `Scale` from 0 about its slot center, and an old one without a partner shall shrink to `Scale` 0 about its old slot center, as outline pieces filled with the block's `Foreground`, over `Tokens.Long` with `Tokens.EmphasizedEase`. In a pair where either character has no outline, the old one shall fade `Opacity` to 0 and the new one fade from 0 over `Tokens.Long` with `Tokens.Ease`. Each is drawn as its outline, or as a text piece in the block's font when it has none.
- **-088** changed: While it morphs, `MorphGlyphs` shall hold the block's width as -081 does. When it completes, the block shall show `text` as plain `Text` with no character hidden, its width released and the canvas removed from the adorner layer.
- Added: When no pair moves, `MorphGlyphs` shall set `Text` to `text` and return a completed `Timeline`, adding no canvas, holding no width and hiding no character.
- Added: When the block's `Text` is set by anything other than the morph while `MorphGlyphs` plays on it, the morph shall complete at once and the block keep the text that was set, its binding intact.
- **-090** changed: When `ReducedMotion` is set as `WriteIn` is called, it shall not split the block and shall fade its `Opacity` from 0 over `Tokens.Short` after `delay`. As `MorphGlyphs` is called with `reduced` `Crossfade`, it shall crossfade as -080. With `Instant`, it shall set `Text` to `text`, leave `Opacity` alone and return a completed `Timeline`.
- **-098** changed: add "and `MorphGlyphs` on a block with no adorner layer" to the blocks that complete at once.
- Added (Defaults): When `reduced` is not given, `MorphGlyphs` shall use `ReducedMorph.Crossfade`.
- Decisions: the bullets above move in. "The text morphs share one running table and their plumbing" becomes "share one running table" (`MorphGlyphs` no longer shares the split, ghosts or overlay host). "`MorphGlyphs` pairs by position, from the end for numbers" gains numerals. "`WriteIn` and `MorphGlyphs` fade when reduced" names the `Instant` option.
- Reduced motion section: `MorphGlyphs` crossfades the unsplit block, or sets it at once with `Instant`.
- Open items: the body-size specks. Equal pairs as text do not touch them, because the specks are unpaired letters collapsing ("Save" → "✓" has no equal pair). Drawing leaving characters as `Foreground` outlines instead of bitmap snapshots removes the likely cause, a snapshot rendered on transparent whose dark antialiasing fringe concentrates as it scales toward 0. Task 7 checks it: if the specks are gone, strike the item; if not, keep it with the new finding.

**BRIDGE-TEXT** (`docs/specs/avalonia-bridge/text.md`):

- **-004** changed: … measuring a copy of the block with its font family, size, style, weight, stretch, letter spacing, font features, wrapping and padding …
- **-055** changed: … whose `Data` is the character's outline (BRIDGE-GLYPHS-001, shaped with the block's font features) …
- Open item added: a character piece is shaped alone, so contextual alternates and kerning across pieces are lost (Inter's `calt` raised colon between figures, BRIDGE-RECIPES decision on hiding instead of splitting).

**BRIDGE-GLYPHS** (`docs/specs/avalonia-bridge/glyph-outlines.md`):

- **-001** changed: add "shaped with the block's font family, style, weight, stretch, size, letter spacing and font features".
- **-003** changed: `TextOutline(text, typeface, fontSize, fontFeatures)` shall return the outline of `text` shaped with `fontFeatures` (none when null) and broken into lines as a `TextLayout` does …
- Added: Read from a laid-out block's text layout, each grapheme's outline shall be the glyphs that layout shaped for it, in context, relative to the grapheme's slot.
